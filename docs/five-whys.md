# Five whys

**Problem:** a payments design partner churns at renewal even though its agents ran.

1. Why? The executive sponsor could not see value at renewal. *(Assumption)*
2. Why? Nobody tracked adoption breadth, approval rate or cost per case in one place. *(Assumption)*
3. Why? The first ops hire was busy answering support and building internal tools by hand. *(Assumption, consistent with the scope in the [job post](https://www.ycombinator.com/companies/runtime/jobs/pNjYg79-founding-ai-ops))*
4. Why? No ranked list of what to automate first, so everything stayed manual. *(Assumption)*
5. Why? No shared system for the four jobs of the seat. *(Assumption)*

**Root cause addressed:** one desk that ranks internal automation (A), keeps customer health and renewal briefs current (B), standardises payment procedures as agent specs (C), turns run failures into fixes (D), and rolls it all into the cadence (E).
