# Brand sheet

Sampled from the live [runtm.com](https://www.runtm.com) on 6 Oct 2026. Mark files are the official SVGs from runtm.com (`brand/runtm-logo-dark.svg`, `brand/runtm-logo-light.svg`), used unmodified.

| Token | Value | Use |
| --- | --- | --- |
| Background | `#f7f6f3` | Page |
| Ink | `#25372c` | Headings, body |
| Muted | `#63715f` | Secondary text |
| Primary | `#344c3e` | Buttons, active states |
| Border | `#dce1d8` | Panels, tables |
| Body font | Inter | Text, headings (500, tight tracking) |
| UI font | JetBrains Mono | Labels, buttons, formulas, tags |

Square-ish buttons (2px radius), thin pale borders, no heavy shadows, pill tags.
