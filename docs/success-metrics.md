# Success metrics

All targets are proposals (Assumption), not Runtime figures.

| Metric | Definition | Target | Where |
| --- | --- | --- | --- |
| Internal agents live | Automation Map items shipped with an owner and success measure | 5 by day 30 | Automation Map |
| Hours saved per week | Measured hours on shipped agents vs. the map estimate | Within 30% of estimate | Automation Map |
| Time to first working queue | Kickoff to first approved agent run for a design partner | ≤ 5 business days | Customer Desk |
| Health coverage | Share of health weight with real data | ≥ 60% every account | Customer Desk |
| Renewal briefs on time | Briefs sent 90 days before renewal | 100% | Customer Desk |
| Run pass rate | Reviewed runs with zero findings | Rising week on week | Run Review |
| Skipped approvals | Runs that acted before a required approval | 0 | Run Review |
| Friction items shipped | Top 3 Friction Log items with a ship date | ≥ 1 shipped per cycle | Run Review |
| Board update on time | Sent on the agreed date, every number traceable | 100% | Operating Cadence |
